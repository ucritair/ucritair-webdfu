Step 1: Get Your Critter Ready

Quickest path: click Start Standard Update first. On compatible firmware, the page will prompt for your Critter's USB serial port and reboot it into bootloader mode automatically.

If that automatic handoff does not work, use one of the manual bootloader methods below, then come back to the same button.

~CAT BOOTLOADER MODE~
Connect to a computer over USB
to download new firmware.

  • Paperclip Poke: Hold down Start + Select + Down. While holding, gently press the reset button with a paperclip. Release the paperclip first, then the buttons.
  • Sleepy Wake-up: If your Critter is asleep, hold Start + Select + Down together to wake it directly into bootloader mode.
  • Menu Method: From the Critter's menu, go to Power → Sleep. Once it is asleep, use the "Sleepy Wake-up" method above.

Once the bootloader screen is showing, plug the Critter into your computer or phone and continue with the standard update button on the left.

Why the refreshes later? μCritter uses a two-stage MCUboot flow. Your browser may need a refresh between stages so it can reconnect to the device cleanly.

Step 2: macOS Pupdate Dance!

Mac pals, follow the status messages next to the Start Standard Update button. It is still a connect-refresh-connect routine, but the bootloader helper now lives in the same card.

  1. Make sure your Critter is plugged in and showing the ~CAT BOOTLOADER MODE~ screen if the automatic handoff did not already do it for you.
  2. Click Start Standard Update.
  3. A browser pop-up will ask for permission. Select MCUBOOT and click Connect.
    Seeing CAT PROTOTYPE? Your Critter is not in bootloader mode yet. Go back to Step 1 and try again.
  4. The status message will tell you when it is time to REFRESH PAGE. Do it with ⌘+R.
  5. After refreshing, the page may ask you to click the button again for Stage 2 permission. If the browser asks, choose MCUBOOT again.
  6. The status will again say REFRESH PAGE AGAIN.
  7. One last time: after the final refresh, click the button if needed and the pupdate should start automatically.

Did it work? Keep an eye on the progress log. "Pupdate Complete!" means success and your Critter will reboot with the new firmware.

Step 2: Windows Pupdate Prep! (Drivers & Restart Required!)

Because Windows needs a little extra help recognizing your Critter during the update, you need a one-time Zadig driver setup and a restart sequence. Please follow these steps exactly.

A. Preparation

  1. Fetch Zadig: Download the latest version from zadig.akeo.ie.
  2. Critter Ready: Make sure your Critter shows the ~CAT BOOTLOADER MODE~ screen and is plugged into your PC.

B. Zadig - Part 1 (Stage 1 Driver)

  1. Run Zadig as Admin: Right-click Zadig and choose "Run as administrator".
  2. Show All Devices: In Zadig, click Options and enable List All Devices.
  3. Find DFU Interface (Interface 2): Select MCUBOOT from the dropdown list (USB ID 2FE3 0100).

    Interface Check: Pick the entry for Interface 2. Do not replace the driver for Interface 0.

    Seeing CAT PROTOTYPE instead of MCUBOOT? Go back to Step 1 and re-enter bootloader mode.

  4. Select WinUSB: Ensure the box next to the arrow shows WinUSB for Interface 2.
  5. Install Driver: Click "Replace Driver" or "Install Driver".
  6. Close Zadig for now.

C. Web App - Part 1 (Trigger Stage 2)

Now use this page briefly to move the Critter into its second update stage.
  1. Click Start Standard Update.
  2. Select MCUBOOT in the browser pop-up.
  3. Wait until the status says the device is switching modes.
  4. Ignore any refresh prompt for now. Leave the Critter plugged in.

D. Zadig - Part 2 (Stage 2 Driver)

Now teach Windows about Stage 2 while the device is still connected.
  1. Run Zadig as Admin again.
  2. Show All Devices again.
  3. Find Stage 2 Device: Select MCUBOOT again from the dropdown.
    In this stage, Zadig should show only one MCUBOOT device.
  4. Select WinUSB again.
  5. Install Driver again.
  6. Close Zadig.

E. The Big Restart (The Windows Driver Shuffle!)

Critical: Windows needs this exact sequence so the new drivers bind correctly.
  1. Physically unplug the μCritter from your PC.
  2. Completely close your browser.
  3. Re-open the browser and come back to this page.
  4. Plug the μCritter back in while it is still showing the bootloader screen.

F. Start Fresh & Pupdate!

After the restart, the driver setup should be complete for both stages.
  1. Click Start Standard Update again.
  2. Follow the prompts:
    • Select MCUBOOT in the browser pop-up when asked.
    • Click REFRESH PAGE when the status tells you to.
    • Click the button again after the first refresh if needed.
    • Click REFRESH PAGE AGAIN when prompted.
    • Click the button one last time after the second refresh if needed.
  3. Pupdate Time! Flashing should begin automatically after the final connection.

Watch the progress log. "Pupdate Complete!" means success and your Critter will restart automatically.

Step 2: Linux Pupdate Prep! (Permissions Time!)

Linux usually needs a quick one-time udev rule so the browser can talk to the Critter.

A. Create udev Rule (Choose One Method)

You only need to do this once per computer.

Method 1: Manual Steps

  1. Open your terminal.
  2. Create or edit the rules file:
    sudo nano /etc/udev/rules.d/51-mcuboot.rules
  3. Paste these lines: 
    SUBSYSTEM=="usb", ATTR{idVendor}=="2fe3", ATTR{idProduct}=="0100", MODE="0666", GROUP="plugdev"
SUBSYSTEM=="usb", ATTR{idVendor}=="2fe3", ATTR{idProduct}=="ffff", MODE="0666", GROUP="plugdev"
  4. Save and exit Nano: Ctrl+X, then Y, then Enter.
  5. Check group membership: run groups and see whether plugdev is listed.
  6. Add yourself to the group if needed:
    sudo usermod -aG plugdev $USER
  7. Reload rules:
    sudo udevadm control --reload-rules && sudo udevadm trigger
  8. Log out and back in if the group membership changed.

Method 2: Bash One-Liner

This command creates the file, adds your user, and reloads the rules:

echo -e 'SUBSYSTEM=="usb", ATTR{idVendor}=="2fe3", ATTR{idProduct}=="0100", MODE="0666", GROUP="plugdev"\nSUBSYSTEM=="usb", ATTR{idVendor}=="2fe3", ATTR{idProduct}=="ffff", MODE="0666", GROUP="plugdev"' | sudo tee /etc/udev/rules.d/51-mcuboot.rules > /dev/null && sudo usermod -aG plugdev $USER && sudo udevadm control --reload-rules && sudo udevadm trigger && echo "Rule created or updated. Log out/in if you were not already in plugdev."

Snap or Flatpak Chromium? You may also need explicit USB access. For Snap Chromium, try sudo snap connect chromium:raw-usb.

B. Linux Pupdate Dance! (After Setup & Login)

  1. Re-plug your Critter after the rule setup and login refresh. It should be in bootloader mode.
  2. Click Start Standard Update.
  3. If the browser asks, choose MCUBOOT and click Connect.
    Seeing CAT PROTOTYPE? Bootloader mode is not active yet.
  4. Click REFRESH PAGE when the status tells you to.
  5. Click the button again after the first refresh if needed.
  6. Click REFRESH PAGE AGAIN when asked.
  7. Click the button after the second refresh if needed. Flashing starts from there.

Watch the progress log. "Pupdate Complete!" means success and your Critter will reboot.

Step 2: Android Pupdate Prep!

You must use Google Chrome on Android for WebUSB to work reliably.

Browser Requirement: Use Chrome on your Android phone. Other browsers usually cannot finish the DFU flow.

A. Get Connected & Check OTG

  1. Make sure your Critter is showing the ~CAT BOOTLOADER MODE~ screen.
  2. Plug Critter into your phone with either a USB-C cable or an OTG adapter.
  3. Enable OTG if necessary. If the Critter is not detected later, check your phone settings for an OTG option.

B. Android Pupdate Dance!

Then follow the messages next to the Start Standard Update button:

  1. Click Start Standard Update.
  2. Choose MCUBOOT when Chrome asks for permission.
    Seeing CAT PROTOTYPE? Your Critter is not in bootloader mode yet.
  3. When the status says REFRESH PAGE, pull down from the top in Chrome until you see the refresh icon.
  4. After refreshing, tap the button again if needed and pick MCUBOOT.
  5. If the page says REFRESH PAGE AGAIN, pull down to refresh again.
  6. Tap the button one last time if needed. The pupdate should then start automatically.

Keep an eye on the progress log. "Pupdate Complete!" means your Critter is ready to reboot and show off.
